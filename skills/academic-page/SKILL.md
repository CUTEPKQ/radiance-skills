# Academic Page

新建页面时从同目录的 `template.html` 开始（配色、字体、组件、动效脚本都已写好）；美化已有页面时把其中的样式与脚本移植过去。

## 配色（固定）

| 色值 | 角色 | 用在哪 |
|---|---|---|
| `#6096B4` | 强调色（10%） | 只给"本文 / 本方案"和每屏最关键的一个结论数字 |
| `#93BFCF` | 次级数据色 | 图表中的普通数据系列 |
| `#BDCDD6` | 结构色 | 弱化条形、分隔、对比方法、空状态（虚线） |
| `#EEE9DA` | 结构色 | 引用气泡、浅色卡片、表格中"本文"行底色 |
| `#FAF8F3` / `#FFFFFF` | 背景（60%） | 页面底色 / 卡片 |
| `#1E2B33` / `#5B6A73` / `#8C979D` | 文字 | 正文 / 次要 / 注释 |
| `#3B6C88` | 链接 | 仅链接文字 |

## 荧光笔法则

- 整页划满等于没划：`#6096B4` 每屏最多一处，只标"本文 / 本方案"或核心结论。
- 小标题、日期、导航高亮、进度条、标签、序号、图标一律用中性色或结构色。
- 比例按 60-30-10：背景中性色 60%，卡片 / 结构 30%，强调 10%。
- 领域固有颜色（如 MRI 分割标签色）保持原样，不强行换成配色。
- 配色外需要额外区分色时，先从配色推导同色系；必须另加时在回复中说明。

## 字体与版式

- 西文与数字：SF Pro Display（标题）/ SF Pro Text（正文）/ SF Mono（数字、代码）。
- 中文：PingFang SC（苹方。SF Pro 不含中文字形，苹方是苹果为其配套的中文字体）。
- 不引外部字体。
- 大标题 + 结论式副标题；每节开头一句话给结论。
- 标题（h1–h4、卡片标题）末尾不加句号「。」。
- 白色圆角卡片（20–24px）+ 极淡阴影；半透明吸顶导航 + 当前章节高亮。
- 不加多余的二级标签和说明文字，让布局自己说明。

## 动效（每一个都要有任务）

- 文字加载即见：标题、正文、表格、数字不做淡入、飞入、数字滚动。
- 每屏只动一处：动的对象必须承担表达任务，比如图表数据呈现、流程或机制的动态演示、状态变化前后对比；不做纯装饰的动效。
- 禁止循环动画和装饰性动画（流程演示需要循环播放时除外）。
- 悬停反馈可保留（卡片轻微上浮、图片轻微放大）。

## 禁止的套路

- 不在标题上方加小标签（eyebrow），如「01 · 数据」。
- 不用中点拼接元信息串，如「Research Memo · 2026.11.08」。
- 不用卡片套卡片、emoji 图标、大面积渐变。

## 内容

- 数字、规模、日期、论文结论必须核实原始来源并注明；查不到标"未核实"。
- 不加"下一步 / 行动号召"区块。
- 只用中文或英文。

## 流程

1. 美化已有文件：先备份为"（原版备份）"，只改样式与动效，不改文字和数据，除非用户要求。改完后对比新旧页面的纯文本，确认文字和数字一致。
2. 大文件（内嵌 base64 图片）先剥离图片再阅读结构；替换样式时保留原脚本与图片。
3. 本地起预览，逐节截图检查：排版、动效是否触发、控制台无报错。
4. 回复说明改了什么、配色外加了哪些颜色、哪些数据未核实。
